# Favicon · olho místico

Gerado com a ferramenta integrada de geração de imagens, com fundo transparente. O PNG foi reduzido para 48×48 com reamostragem Lanczos, preservando o canal alfa. O ICO contém versões de 16×16, 32×32 e 48×48.

Arquivos usados pela aplicação: `infrastructure/nginx/assets/favicon.png` e `infrastructure/nginx/assets/favicon.ico`.

## Prompt usado

Use case: logo-brand. Create one mystical eye favicon icon for a fantasy web security game named Mystical Oracle. Final use at exactly 48x48 pixels: extremely legible simple bold silhouette, centered single almond-shaped open eye, luminous golden outline, violet iris with a dark vertical pupil, a very restrained cyan mystical accent. Match the existing site's gold, purple and cyan occult palette. Square composition, large eye filling most of canvas with a narrow safety margin. Transparent background with real alpha, no solid backdrop, no checkerboard drawn, no text, no letters, no watermark, no mockup. Crisp thick graphic shapes and minimal ornament so the icon remains recognizable at 16x16 and 48x48. Generate a square PNG master suitable for downscaling.
